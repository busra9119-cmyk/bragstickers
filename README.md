# Brag Stickers — Chromebook Persistence Test

This is the clean classroom version, with **no students preloaded**. All artwork is built into `index.html`; no extra asset folders are needed.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example, `brag-stickers-test`).
2. Upload **index.html** to the repository root (you may also upload this README).
3. In **Settings > Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
4. Open the GitHub Pages URL in Chrome on the classroom Chromebook.

## Test local saving
1. Sign into the Chromebook with the teacher's usual school Google account. **Do not use Guest or Incognito mode.**
2. Open the published GitHub Pages URL.
3. Add a fictional test student and award two stickers.
4. Close Chrome, reopen the **same URL**, and confirm the student's name and stickers remain.
5. Shut down the Chromebook completely, restart it, sign in, reopen the **same URL**, and check again.
6. Separately test signing out of ChromeOS and signing back in, because school-managed devices may erase local data at sign-out.
7. Save a backup and test restoring it (using fictitious test data).

## Important
- Records are saved locally inside Chrome for the **website and ChromeOS profile**. They are **not automatically synchronized between different devices**.
- Use the **same published URL** for each test. A `file://` local HTML version and GitHub Pages use different browser storage.
- Clearing site data, switching ChromeOS profiles, school policies that erase local profiles, or resetting a Chromebook can remove local records.
- Keep periodic backups in Google Drive, especially before Chromebook resets or changes.
- Test using fictional students first, and follow school policy before entering real names.
